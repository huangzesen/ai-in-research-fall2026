# Homework 1: the hardest task in your field

**Due before class, Wednesday, October 7, 2026.**

Design the hardest task you can in your own field: one a top expert could do, with an answer a program can check, that today's best AI agents likely can't. Package it so an AI agent can attempt it on its own, in a sealed container, graded automatically. An AI coding agent does the engineering with you; then watch a frontier agent try. Students, auditors and faculty are all welcome.
